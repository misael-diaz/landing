Motivation

Recently, I have stopped relying on the network manager provided by the Linux desktop environment because it was failing sometimes. This signaled me to find an alternate approach to connect to the wireless network.

On Linux knowing command-line tools is more important than knowing your way around the Graphical User Interface (GUI). It's on times like this when the linux desktop manager fails you that you can leverage the command-line tools to connect to the wireless network. Talk about empowering the users of a platform, this is one of the reasons I have been using linux for over a decade and probably will continue to do so.

One last thing, this is a practical guide that only tries to walk you through the process of connecting to a wireless network from the command-line interface. There's much to learn about linux and so my recommendation is that you read the man pages of the commands that caught your attention because I am not writing everything that you might want to know about networking, instead I am writing the bear minimum to get you going.

Connecting to a Wireless Network

Open up your terminal, we are going to connect to the WiFi network through command-line however this is not necessarily a walk in the park in general.

Listing Wireless Capable Network Interfaces

The fastest way to know if your system has a wireless capable interface is to execute iwconfig without arguments, you may even perform this step as a regular user: 

iwconfig

The output could be something similar to this: 

  • enp0s31f6  no wireless extensions.
  • wlp0s20f3  IEEE 802.11  ESSID:off/any
  • lo  no wireless extensions.

Some of the output was omitted for brevity but surely you have noticed that in this example the only wireless capable interface is the wlp0s20f3 interface.

Scanning for Available Wireless Networks

Now that you know the name of the wireless capable interface you can bring it up so that you can scan what wireless networks are available near your linux machine. However to achieve that you will need system administration privileges and so now it's the time to do so via: 

sudo su

I am assuming that your user is in the sudoers list, if not you will need to know the root password to login as the root user via: 

su -l root

Experienced linux users know that they can use a shorter version (they would not be reading this blog anyways because they already know), I decided to show the most verbose way of doing it to make it evident to new linux users.

The first thing you need to do is to bring the wireless network capable interface up so that you can scan for wireless networks in your area: 

ip link set wlp0s20f3 up

Note that you would be replacing wlp0s20f3 in the command line string with the name of the wireless capable network interface of your linux machine.

Now you can scan for wireless networks via: 

iwlist wlp0s20f3 scan

Again experienced linux users know that you can omit the network interface name from the command-line string but again for the benefit of the new linux users I am writing the longer version. The output of that command is going to be lengthy so probably you would want to match essid's and you can do that in this way: 

iwlist wlp0s20f3 scan | grep -i essid

What we are doing here is to effectively filter the output of the wireless scan so that any output line containing the essid string will match and will be present on the output, anything else will be filtered out and so it will not be shown. The output would be something like this:

  • ESSID:"Wireless-Network-1"
  • ESSID:"Wireless-Network-2"
  • ESSID:"Wireless-Network-3"

The wireless network that you may want to connect to is probably going to show up in that list. At this point you are ready to write the configuration file that the WPA supplicant, which is the client that will use to connect to the wireless network.

It's likely that the configuration file for the WPA supplicant is already present in your system. The file I am referring to is /etc/wpa_supplicant/example.conf. If not you can always create it, I am assuming that if you are here you know your way with creating files and editing them with a text editor.

  • network={ 
  •   ssid="home"
  •   scan_ssid=1
  •   key_mgmt=WPA-PSK
  •   psk="very secret passphrase"
  • }
