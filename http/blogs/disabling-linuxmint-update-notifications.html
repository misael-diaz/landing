Disabling Notifications from the Linux Mint Updater at Startup

In this article you will learn how to use the command-line interface to disable the notifications that the Linux Mint System Updater generates at startup time.

Motivation

I don't know about you but I don't like distractions, especially when I turn on my computer I don't want reminders about taking care of the system. What I want is to get my work done. I can do system administration on the weekends if I need to but it's up to me not up to the system. I know Linux Mint tries to be considerate on the frequency of the reminders but as you can see even its level consideration drove me to this point.

Removing the Linux Mint Update Launcher from Autostart Applications

Disabling the notifications from the linux mint updater is as simple as moving a file from one location to another. If you are ready to do this, follow along, it will be brief and swift.

Open up your terminal and then switch to the root user with your credentials. And change directory to /etc/xdg and create a new directory, you may call it anyway you want though to place the Linux Mint Update Manager linuxmint.desktop.

Currently the Linux Mint Update Manager linuxmint.desktop should be located in the autostart directory and so all that we need to do is to relocate the autostart file this way: 

mv autostart/linuxmint.desktop disabled-autostart

And that's all folks, you need not take any further action. I assure you that you won't miss those notifications from your desktop session.

A few comments that might be of your interest. As you can see I have chosen disabled-autostart as the directory that will host the Linux Mint Updater. If I ever need to restore the normal behavior it would be easy to remember where it is. However, I don't see that that day will ever come.

This was surely a short one I know but this is one of those things that if you don't document it somewhere you may forget by the time that you need to do it again. And so I decided to write a mini blog about this for my future self. Hopefully this would also help someone out there on the internet. Cheers!
